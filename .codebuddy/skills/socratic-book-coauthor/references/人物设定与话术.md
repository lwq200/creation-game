# 人物设定与话术库

> 本文件供写作者随时查阅，防止角色走形。两角色设定**跨书固定**，任何新书沿用。


## 一、造物主（学习者 / 读者替身）

### 身份

初学者视角，读者的替身。好奇、爱追问、会犯错、直觉模糊但能瞎猜。

### 功能

- 替读者问出「为什么」「凭什么」「怎么来的」。
- 把知识诞生的每一步走一遍，允许走错路再被纠正。
- 走错路、被拆穿后要有真实的「被按在墙角」「心头一紧」的反应，让读者有共鸣。

### 话风

口语化，带真实困惑：

- 「等等，那这个约定是谁定的？凭什么？」
- 「这还不简单，用二进制啊。」
- 「因为……二进制简单？计算机算二进制快？」
- 「那……难道是电路实现上，两种状态比十种状态容易做？」
- 「所以是物理上不可靠，才退而求其次用两态？」

### 行为模式（新增「错误侦测型」）

1. 先凭直觉给一个「想当然」的答案（通常是错的或半对）。
2. 自己把答案代入实际计算/操作，**自己发现矛盾**（算到一半发现 5+(-5)=-10，而非等老谟指出）。
3. 自己描述矛盾：「等一下……如果按我这样算，那这里不就不成立了吗？」
4. 在老谟引导下自己迈出正确一步（「把 -5 定义成 256 减 5？」）。
5. 顿悟后能**自己总结**成一句人话（「我不是发明了负数，我是发明了怎么把负数藏进正数里的编码」）。
6. 每章结尾，由造物主亲口说出本章核心认知，作为推导闭环。


## 二、老谟（毒舌导师）

### 身份

毒舌导师。风趣毒舌、一针见血、专治想当然；偶尔阴阳怪气，但教学逻辑极其严密。

### 功能

- 不直接给答案，先用反问逼造物主自己推出结论。
- 拆穿错误直觉（指出「想当然」的具体出处）。
- 在推导完成时才给出关键定义/约定（补码、Unicode、布尔代数等术语都在造物主自己走到之后才落锤命名）。
- 承担「引子」里抛出本章问题、结尾预告下章职责。

### 话风

先戳破再点拨。毒舌要**自然**，不硬凹不尴尬：

- 「先别急着记结论。这东西如果让你从零造，你第一步会干什么？」
- 「你是觉得……对吧？错。想想你刚才自己说的话，哪一步漏了？」
- 「你把『理所当然』四个字给我划掉，重新说。」
- 「问得好。这个『凭什么』，就是本章要推导的东西。」
- 「快？二进制在数学上可一点不比十进制『快』。你那『简单』两个字，是从哪儿偷来的？」
- 「你总算会说人话了。」
- 「亲爱的，先把你那套哄人的感慨收起来。」

### 毒舌类型（可混用）

1. **戳破想当然**：指出对方答案里「偷来的」常识。
2. **反讽**：「听起来很讲道理。」然后立刻用反例拆掉它。
3. **顺势点拨**：造物主说对了一半，先肯定再补全（「这才沾到点边」）。
4. **落锤命名**：造物主已经推出，老谟才给出正式术语和历史出处。
5. **放大矛盾（新增）**：不直接说「你错了」，而是让造物主重复自己的话，自己看见矛盾。「先别回答。把你刚才说的那句话，再念一遍——然后告诉我，它和你上一轮的结论，是不是同一条路。」

### 毒舌的底线（质量红线）

- 可以犀利，不能凶残、不能人身攻击、不能贬低求知欲。
- 毒舌永远服务于「拆掉错误直觉」这一教学目的，不为了毒舌而毒舌。
- 每一句毒舌背后必须有具体的教学理由：戳的是哪个误区、导向哪步推导。


## 三、话术对照表

| 场景 | 造物主 | 老谟 |
|------|--------|------|
| 章首 | 把上章的困惑/直觉带进来，提出傻瓜问题 | 戳破问题本身问反了，抛出本章真正的起点 |
| 第一轮误区 | 给出想当然答案 | 「你的『……』是从哪儿偷来的？」 |
| 推导中途 | 猜对一半，不确定 | 「这才沾到点边。」然后补全逻辑 |
| 撞墙 | **自己算出荒谬结果，自己描述矛盾** | 不直接指出错误，问「你发现矛盾了。现在，说说你想怎么绕过去。」 |
| 顿悟 | 自己说出结论 | 「你总算会说人话了。」或落锤命名 |
| 章尾 | 总结核心认知 | 预告下章，抛出新问题 |


## 四、反面示例（禁止出现）

- ❌ 造物主秒懂一切，从不犯错 → 失去读者替身功能。
- ❌ 老谟直接灌输结论：「记住，这就是补码。」→ 违背苏格拉底原则，应先逼问再命名。
- ❌ 老谟骂人/嘲讽求知：「这都不懂？笨死了。」→ 毒舌不等于侮辱。
- ❌ 造物主突然变得博学，引用历史细节 → 历史由老谟或【历史溯源】提供，造物主保持初学者视角。
- ❌ 术语在推导前出现 → 任何术语必须等造物主「走到门口」才命名。
- ❌ 造物主等待老谟指出错误，而非自己发现 → 违背「错误侦测型」原则。
