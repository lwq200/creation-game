# 创世游戏 · Socratic Book Coauthor

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

**苏格拉底对话体共创技术/教育类书籍的 AI 写作工作流（Skill）。**

毒舌导师「老谟」与「造物主」（读者替身）一问一答，让读者**从零重新推导**知识体系——每一个概念都在对话中「重新发明」一遍。不是灌输结论，是把知识诞生的每一步踩给你看。

---

## 核心特性

| 特性 | 说明 |
|------|------|
| 🤖 **苏格拉底追问** | 老谟用 2-3 轮反问逼你（造物主）自己推出结论，答案永远是被推导出来的 |
| 🧱 **从零推导** | 每章从一个"傻瓜问题"出发，让读者经历知识的诞生过程 |
| 🔧 **实现思维深度** | "如果让你造一个，你会怎么做？"——把读者从"看懂"推向"能造" |
| 📜 **意义来自约定** | 显式点明底层规则是约定，不是天经地义 |
| 📊 **计算板块分离** | 原理对话与计算实操清晰分离：速查表 + 工程案例 + 踩坑记录 + 自测题 |
| 👥 **多 Agent 协作** | 支持多 agent 分批写作 + reviewer 跨章质量审查 |
| 📖 **宁深勿浅** | 每个知识点都讲深讲透、让读者能「亲手造出来」 |

## 快速使用

### 1. 加载工作流

将 [`skills/socratic-book-coauthor/`](skills/socratic-book-coauthor/) 交给你的 AI 助手（放入其 skills/指令目录，或直接粘贴 `SKILL.md` 全文），即获得完整的写作方法：人物设定、核心原则、五阶段流程、质量检查清单。仓库根目录还附有打包好的 [`socratic-book-coauthor.zip`](dist/socratic-book-coauthor.zip)。

### 2. 最简起步：一句话开始写书

对 AI 说一句**你想写的书**，例如：

> 我想写一本《从汇编到高级语言》，用老谟和造物主对话体，从第一册最后一章的疑问接着写。

AI 会按流程自动推进：

```
第 1 步 → 先调研外部课纲，产出《蓝图 v0.1》给你确认
第 2 步 → 确认后生成《补充计划 v0.2》（章节级设计）
第 3 步 → 逐章写作（每章 ≥6 轮对话、≥5000 字）
第 4 步 → 按 13 项清单质量检查
第 5 步 → 统稿组装、打包交付
```

### 3. 常用指令

| 场景 | 示例 |
|------|------|
| **新书** | "用老谟造物主对话体写一本《XXX》，主题是……" |
| **续写** | "继续第 N 章" / "接着上一章的疑问写下一章" |
| **单章** | "把 X 概念单独写成完整的一章" |
| **多书协作** | "启用多 agent 协作，分 3 批写完，每批交 reviewer 审查" |
| **拆章** | "这章太长了，宁深勿浅，拆成两章" |

## 人物设定

| 角色 | 身份 | 话风 |
|------|------|------|
| **老谟** | 毒舌导师，风趣一针见血，专治想当然 | "先别急着记结论。如果让你从零造，你第一步干什么？" |
| **造物主** | 初学者替身，好奇、爱追问、会犯错 | "等等，那这个约定是谁定的？凭什么？" |

## 创作流程

五阶段工作流：

```
蓝图 v0.1 → 补充计划 v0.2 → 章节写作 → 质量检查 → 统稿组装
```

| 阶段 | 产出 | 关键动作 |
|------|------|----------|
| **蓝图** | 全书骨架 | 外部课纲调研 → 按认知依赖重排 → 每章一句话主题 + 切入问题 |
| **补充计划** | 章节级设计 | 知识点拆分、预计对话轮数、风险登记 |
| **章节写作** | 每章 `.md` | ≥6 轮对话、≥5000 字、Mermaid 图、计算板块分离 |
| **质量检查** | 评审报告 | 13 项必过清单（对话轮数、字数、推导自洽、人设一致等） |
| **统稿组装** | 成品书 | 统一语气/篇幅、章节衔接、打包分发 |

## 为什么叫"创世游戏"

每一章都是一个"创世关卡"——给你一堆最原始的积木（比特、开关、0/1），让你亲手造出一个概念世界里的东西：数、逻辑、函数、导数、矩阵、概率……你不是在"学"数学，你是在用最底层的原料，**亲手把数学重新发明一遍**。
