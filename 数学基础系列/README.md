# 《数学基础》系列 · 从样书到完美自学教材

> 样书《数学基础》（17 章）拆分重铸为 **7 册独立教材**。每册聚焦一个领域，补上样书刻意回避的**严格性**（ε-δ、对角化充要条件、凸性、勒贝格积分、频率学派），并为每一章新增**计算训练场**（中大型计算题 + 完整分步解答）。
>
> 目标：读者读完不再只是"能把数学翻译成大白话"，而是**对着空白纸能算、能证**——这才是"教材"而非"读物"的信用。

---

## 为什么拆

样书的核心短板（详见 `丛书蓝图_v0.1.md` 的诊断）：

| # | 样书缺陷 | 系列对策 |
|---|----------|----------|
| 1 | 自测题几乎全是概念辨析/简答，无 10 分钟+ 计算题 | 每章新增「计算训练场」：≥2 道中大型计算题，附完整分步解答 |
| 2 | 刻意回避严格性（ε-δ、对角化充要条件、勒贝格积分） | 每章新增「严格化走廊」：定义→定理→证明→反例，≥1 个可复写证明 |
| 3 | 贝叶斯立场偏移，频率派被压缩成脚注 | 概率册双轨并述，显式标注「这是一条进路，另一条路另述」 |
| 4 | 最优化缺凸性分析 | 多元优化册单设「凸性」章：凸函数、凸性判定、鞍点 vs 局部最优 |
| 5 | 头重脚轻（后 5 章报菜名） | 信息论、图论、可计算性各自独立成册，给足篇幅 |
| 6 | 对话文学惯性打断证明 | 「证明优先于文学」红线：公式/定理直接陈述，文学停顿只用于引子与衔接 |

## 每册标配（继承 skill 升级后的两铁律 + 三红线）

- **严格化走廊**：定义（精确）→ 定理（带全前提）→ 证明（≥1 个可复写）→ 反例/边界
- **计算训练场**：≥2 道中大型计算题（动笔 10 分钟+），附完整分步解答
- **学派中立**：贝叶斯/频率、黎曼/勒贝格等分歧显式标注进路
- **节奏平衡**：抽象板块（信息论/图论/可计算性）不报菜名
- **证明优先于文学**：公式/定理直接陈述

## 快速使用

1. 从 `丛书蓝图_v0.1.md` 通读拆分逻辑与全书路线图。
2. 打开目标册的 `蓝图_v0.1.md`，即得该册章节表、严谨推理补点、计算训练设计。
3. 对 AI 说一句：「用老谟造物主对话体，按 `册NN-XXX/蓝图_v0.1.md` 写第 1 章」，即可逐章开写。
